ЧестныйРозыгрыш

Публичная оферта на предоставление доступа к сервису «ЧестныйРозыгрыш»

Редакция от · Сайт:

1. Общие положения

  1. (далее — Исполнитель) предлагает любому дееспособному лицу (далее — Пользователь) заключить договор на условиях настоящей оферты (ст. 435, п. 2 ст. 437 Гражданского кодекса РФ).
  2. Акцептом оферты является оплата выбранного тарифа. С момента оплаты договор считается заключённым на условиях оферты в редакции, действующей на дату оплаты (п. 3 ст. 438 ГК РФ).
  3. Регистрация на сайте и использование бесплатного демо-режима означают согласие с условиями оферты в части, применимой к бесплатному использованию.

2. Предмет договора

  1. Исполнитель предоставляет Пользователю доступ к онлайн-сервису «ЧестныйРозыгрыш» (далее — Сервис) на оплаченный срок. Сервис позволяет проводить розыгрыши по публикациям во ВКонтакте: собирать данные участников через официальный API ВКонтакте, проверять выполнение условий, выбирать победителей проверяемым генератором случайных чисел и формировать публичный отчёт.
  2. Доступ предоставляется в формате «как есть». Состав функций Сервиса может изменяться; изменения, ухудшающие оплаченные возможности, не применяются к уже оплаченному сроку.
  3. Сервис является инструментом. Организатором розыгрыша, ответственным за его условия, информирование участников, вручение призов, уплату налогов и соблюдение законодательства и правил ВКонтакте, является Пользователь.

  2. Оплата производится банковской картой или иными способами через платёжный сервис ЮKassa. Данные банковской карты вводятся на стороне ЮKassa и Исполнителю не передаются.
  3. Доступ открывается автоматически после подтверждения оплаты. Если доступ ещё действует, новый срок прибавляется к его окончанию.
  4. Кассовый чек направляется на e-mail Пользователя в соответствии с законодательством РФ.

4. Права и обязанности сторон

  1. Исполнитель обязуется обеспечивать работу Сервиса, за исключением времени профилактических работ и обстоятельств, указанных в разделе 6.
  2. Пользователь обязуется использовать Сервис только для законных розыгрышей, не передавать доступ к своему аккаунту третьим лицам и не пытаться нарушить работу Сервиса.
  3. Исполнитель вправе приостановить доступ при нарушении Пользователем условий оферты, уведомив его по e-mail.

5. Публичность отчётов

  1. Отчёт о каждом розыгрыше доступен по ссылке любому лицу. В отчёт включаются общедоступные данные участников из ВКонтакте (имя, ссылка на страницу, фотография профиля, результат проверки условий).
  2. Отчёты не изменяются и не удаляются по запросу организатора: в этом смысл проверяемости розыгрыша. Отчёт показывает, сколько розыгрышей проводилось по той же публикации.
  3. Участник розыгрыша вправе обратиться к Исполнителю по вопросам обработки его персональных данных в порядке, описанном в Политике обработки персональных данных.

6. Ответственность

  1. Сервис получает данные через API ВКонтакте. Исполнитель не отвечает за ограничения, изменения или недоступность API ВКонтакте и сторонних сервисов (в том числе публичного маяка случайности drand), а также за действия администрации ВКонтакте.
  2. Исполнитель не отвечает за условия розыгрыша, выбранные Пользователем, вручение призов и споры между Пользователем и участниками.
  3. Совокупная ответственность Исполнителя ограничена суммой, уплаченной Пользователем за текущий оплаченный срок.

7. Возврат денежных средств

  1. Пользователь вправе отказаться от договора в любой момент. По его письменному обращению на e-mail Исполнитель возвращает стоимость неиспользованной части оплаченного срока пропорционально оставшимся дням.
  2. Возврат производится тем же способом, которым была произведена оплата, в течение 10 рабочих дней с даты получения обращения.

8. Персональные данные

Обработка персональных данных осуществляется в соответствии с Политикой обработки персональных данных и на основании согласия на обработку персональных данных, которое Пользователь даёт при регистрации.

9. Прочие условия

  1. Исполнитель вправе изменять оферту, публикуя новую редакцию на этой странице. Новая редакция применяется к оплатам, совершённым после её публикации.
  2. Споры разрешаются путём переговоров, а при недостижении согласия — в суде по месту нахождения Исполнителя с учётом прав потребителей, предусмотренных законодательством РФ.
  3. К отношениям сторон применяется право Российской Федерации.
